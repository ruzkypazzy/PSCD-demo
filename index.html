How it works

One job: tell you whether your symbol is taken before you deploy.

  1. Scan blocks via eth_getLogs, filtered to Transfer events with topic1 = 0x0…0 (the canonical mint). Batched 1,000 blocks per call.
  2. Look up each unique token's symbol() (0x95d89b41), name(), and decimals() via eth_call in parallel.
  3. Decode the ABI-encoded string return values, normalize (case-insensitive, strip whitespace).
  4. Match against your candidate. Return collisions as a list of "trading cards".

Verdicts

CLEAR — no token uses this symbol in the scanned range.
COLLISION — one or more tokens share the symbol. Don't deploy without a rename.
EMPTY — you didn't provide a symbol.

Install as an agent skill

PSCD ships as a Pharos Agent Center skill. Install it once and your agent can call the checker as a tool.

  1. git clone https://github.com/ruzkypazzy/Pharos-Symbol-Collision-Detector-PSCD-
  2. Copy SKILL.md into your agent's skill directory (e.g. ~/.pharos/skills/).
  3. Ask your agent: "is SKP taken on Pharos?"

The agent auto-loads SKILL.md, runs the bash or Python checker, and returns the same verdict + collision list you see above — exactly the JSON schema in SKILL.md.
